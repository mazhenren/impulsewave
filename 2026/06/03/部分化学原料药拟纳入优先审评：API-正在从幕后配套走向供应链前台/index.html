部分化学原料药拟纳入优先审评：API 正在从”幕后配套”走向供应链前台

监管第一次把部分原料药，从制剂背后的配套物料，明确放到药品供应链安全的关键节点上。文件没有附具体品种清单，但它改变的是判断一个 API 是否重要的标准。

2026年6月 · youliao.info

「不是所有原料药都值得优先，但有些原料药，已经不只是原料药。」

01 文件明确了哪三类原料药

国家药监局综合司于 6 月 2 日就《关于明确部分化学原料药纳入药品上市许可申请优先审评审批工作程序的通告（征求意见稿）》公开征求意见，反馈截止 6 月 12 日。文件明确三类化学原料药可纳入药品上市许可申请优先审评审批程序。

第一类 · 关联使用型

临床急需短缺药品制剂，以及其他已进入优先审评的制剂，其关联使用的化学原料药。此类不再单独走申请、审核、公示，直接纳入优先通道。

第二类 · 国产补位型

已上市制剂仅有境外原料药来源时，同品种首家申报上市的境内化学原料药，可提出优先审评申请。

第三类 · 原研本地化型

已在我国上市的原研制剂所用境外化学原料药，申请境内上市并单独审评审批的，可提出优先审评申请。

02 这不是放松审评，是定向提速

优先审评不降低质量标准，改变的只是审评资源的配置顺序。文件的落点不是所有 API 都更快，而是特定 API 更快。

三类 API 有一个共同点：都直接关系到药品供应链的稳定性。要么是短缺药与临床急需药背后的供应，要么是境外单一来源需要国内补位，要么是原研供应体系进入中国监管体系的本地化。

最能说明问题的是第一类：原料药随制剂一起被带入优先通道，不再单独申请。这等于把原料药与制剂的审评时序绑在一起。监管管的不再只是制剂能不能快，而是整条供应链能不能同步快。原料药的审评管理逻辑，正从”配合制剂申报”转向”服务供应保障”。

03 API 的价值正在被重新定价

过去判断一个 API 的价值，看四件事：有没有市场、有没有价格、有没有下游制剂、有没有竞争对手。

这份文件之后，要再加几个问题：它是否被关键制剂依赖，是否只有境外来源，是否关联短缺药与临床急需药，是否属于原研制剂供应链，是否存在国内首家补位的机会。

结论很直接：API 的价值不再只由市场规模决定，也由它在供应链上的位置决定。一个市场规模不算大的品种，只要卡在短缺药保障或境外单一来源替代的链条上，战略价值就会被明显抬高。

过去的估值维度 市场规模 价格水平 产能成本 竞争对手数 新增的供应链维度 是否被关键制剂依赖 是否境外单一来源 是否关联短缺药 国内首家补位机会
04 原料药企业接下来该做什么

对原料药企业，这份文件指向三张需要立刻建立的清单。

境外 API 依赖清单。 筛选标准是：下游制剂已经上市、临床有实际用量、当前原料药来源集中在境外、国内供给不足。同时满足这四条的品种，才具备国产首家补位的政策通道价值。

优先审评制剂关联 API 清单。 制剂进入优先审评，关联原料药可能被一并带入。企业不能只盯 API 自身的登记状态，还要盯上游制剂的审评状态。

原研制剂 API 来源清单。 原研制剂的境外 API 申请境内上市，意味着原研供应体系与中国监管体系的衔接在加强，这会影响后续的供应链合作与质量标准对接。

估值重构： API 的价值 = 市场规模 × 供应链位置。只看产能与价格的时代正在过去。

卡位先于产能： 行业机会从”低成本供给”转向”关键供应链卡位”。信息能力开始与生产能力并列——谁更早识别政策关注的供应链节点，谁更早布局。

立即可做： 同步建三张清单——境外单一来源依赖、优先审评制剂关联、原研制剂 API 来源——锁定国内首家补位窗口。
