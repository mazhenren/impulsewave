原料药市场情报调研分析框架

发表于2026-11-12|更新于2026-11-12
|浏览量:

一、 总则：框架定位与基调

  1. 框架目的：本框架旨在为药厂原料药的市场情报调研工作确立顶层设计、统一认知基调。本框架是未来所有调研工作的指导准则，而非当前立即启动的具体执行计划。
  2. 核心基调：以业务问题为驱动，以分级数据源为基石，通过严格的交叉验证，产出高质量的调研交付物。
  3. 阶段说明：本框架聚焦于“定大纲、定基调”的蓝图规划。关于具体的数据采集执行、分析报告撰写等落地工作，将严格遵循本框架在未来按周期逐步展开，当前阶段不作为重点。

二、 调研目标：业务问题驱动（第一层）

情报调研必须始于业务需求，杜绝“为了做情报而做情报”。核心目标锁定以下四大业务导向：

  • 品种机会评估：发掘潜力品种，评估市场准入机会。
  • 竞争格局分析：洞悉市场份额与竞争对手动态。
  • 价格走势预判：把握市场价格波动规律与趋势。
  • 客户拓展赋能：识别下游客户与渠道拓展方向。

三、 情报内容：六大维度（第二层）

围绕业务目标，构建全面、结构化的六大情报维度：

  1. 法规准入动态（已有基础）：
    • _基调_：该维度可直接复用现有的 CEP、DMF、NMPA、JMF 等情报数据基础，无需重复造轮子，注重更新与动态监测。
  2. 市场需求：关注整体规模、下游制剂需求变化、专利悬崖带来的机遇。
  3. 供给与产能：追踪厂商格局、产能变化及扩产/停产动态。
  4. 价格走势：监测价格指数变化及海关出口量数据。
  5. 竞争格局：分析市场集中度、注册备案差异对比。
  6. 客户与渠道：梳理制剂厂、代理商及采购动态。

四、 数据源体系：分级采信原则（第三层）

为确保情报的准确性与权威性，建立严格的数据源分级采信机制：

  • P0 官方一手：EDQM、FDA、CDE、PMDA等官方数据，作为最高优先级，具备一锤定音的效力。
  • P1 权威二手：行业报告、券商研报等，作为重要补充，需关注其逻辑与发布时间。
  • P2 专业社区：CPHI展会、专业媒体，用于获取行业前沿动态与线索。
  • P3 一般参考：百科、论坛等，必须进行交叉验证方可采信，严禁作为单一决策依据。
  • _基调要求_：在后续所有情报调研中，数据源的选取必须严格对照此分级标准。

五、 交付物形态：分层输出（第四层）

根据不同的业务场景和受众，确定三类核心交付物：

  • 深度研究报告：针对特定行业全景或重大课题，进行一次性深度剖析。
  • 周期情报简报：面向月度更新，延续情报局日常监测，形成动态感知。
  • 品种一页纸：聚焦单分子画像与竞争对比，追求极简与高度浓缩，便于决策层快速阅览。

六、 实施流程：方法论基调（底层逻辑）

确立标准化的情报加工流程，作为未来所有调研项目必须遵循的准则：

范围界定 → 数据采集 → 交叉验证（≥3源） → 分析建模 → 报告产出 → 周期更新

  • _基调强调_：必须坚守“交叉验证（≥3源）”原则，这是保障情报质量和规避误判的底线。

七、 结语：后续工作原则

本框架经确认后，将作为药厂原料药市场情报调研的基准纲领。

后续的情报工作须在本框架的指导下进行。关于具体的实施阶段划分、数据采集任务分配、分析报告撰写（阶段②-⑤）等执行动作，将在本框架基调下，根据业务优先级和资源情况另行制定执行计划，当前阶段不急于推进。

使用建议：这份文档可以作为您向领导或团队进行汇报的纲要，展示整个情报体系的“骨架”和“游戏规则”，完美契合了您“定大纲、定基调”的核心诉求。
