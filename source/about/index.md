## 这个站点是什么

「股票期货外汇技术分析笔记」是一个个人交易研究记录站，围绕三个市场展开：股票、期货、外汇。

这里不写行情点评，也不做荐股。记录的对象是三件更慢的事：

- **方法**：一套可重复的技术分析流程——趋势结构如何判定、关键位如何标注、信号在什么条件下才算成立。
- **复盘**：每一笔交易的理由、入场依据、止损位置、离场结果，以及当时判断错在哪里。
- **风控**：仓位、杠杆、单笔风险敞口与账户回撤之间的关系，比任何指标都更决定长期结果。

## 内容组织

| 栏目 | 记什么 |
| --- | --- |
| 股票 | 趋势跟随、板块轮动、个股结构与仓位管理 |
| 期货 | 杠杆约束、合约节奏、基差与展期对技术信号的影响 |
| 外汇 | 24 小时市场的时段结构、美元周期与主要货币对 |
| 技术分析 | 形态、均线、量价、指标的原理、适用边界与证伪方法 |
| 交易笔记 | 阶段总结、错误清单、规则迭代记录 |

## 写作原则

1. **可证伪**：任何结论都要写清成立条件和失效条件，事后可对照检验。
2. **有边界**：明确说明方法在什么市场、什么周期、什么波动环境下不适用。
3. **不承诺收益**：只记录过程和逻辑，不展示无法核验的业绩。
